# Asistente experto en NetSuite

Este es un chatbot diseñado para responder preguntas sobre NetSuite, utilizando como base de conocimiento la documentación oficial proporcionada en la carpeta `datos`.

## Cómo usar

1.  Asegúrate de tener Python y pip instalados.
2.  Instala las dependencias con `pip install -r requirements.txt`.
3.  Crea un archivo `.env` con tu API key de Google (por ejemplo, `GOOGLE_API_KEY=tu_api_key`).
4.  Ejecuta la aplicación con `streamlit run app.py`.
